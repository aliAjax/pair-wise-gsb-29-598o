# 城市末端配送 · 调度控制台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 逻辑冒烟测试：`./node_modules/.bin/esbuild scripts/smoke.ts --bundle --platform=node --format=esm --outfile=/tmp/smoke.mjs && node /tmp/smoke.mjs`

## 功能

调度台围绕「时段容量 + 余量分配 + 距离路线」组织：

- **骑手排班**：为每个骑手按配送时段维护最大载单量（0 表示该时段不排班），可停用/删除骑手。
- **自动分配**：新订单按时段和余量分配（均衡装载 / 顺序占满两种规则），全员满载时留在待分配区。
- **路线排序**：同一骑手先按时段顺序、时段内按距离从近到远排列，配送员照单顺序送即可。
- **送达与存档**：送达即从路线移出并记录完成时间，进入独立的本地存档，可按骑手/时段筛选。
- **手动改派**：调度员可把待分配或在途订单改派给其他骑手或退回待分配区，满载骑手不可选，改派后两侧路线与统计立即重算。
- **容量联动**：收紧骑手时段容量时，最远的超额订单自动退回待分配区。
- **分开存档**：订单地址、骑手排班、分配规则、送达存档分别以独立 localStorage 键保存，重新打开页面可接着调度；存档页可一键恢复演示数据。

页面分为五个标签：调度台、订单地址、骑手排班、分配规则、本地存档。
