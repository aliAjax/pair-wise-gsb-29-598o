# 城市末端配送调度台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Pinia、Leaflet（依赖保留备用）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 预览：`npm run preview`

## 功能

### 调度台
- 按时段切换视图，展示每个时段「在途 / 最大载量 / 余量 / 待分配」总览。
- 左侧**待分配区**：自动分配装不下的订单留在这里；可逐单改派给任一有余量的骑手，或一键再分配。
- 右侧**骑手路线**：同一骑手同一时段的订单严格按距站点距离由近到远排序，带顺序编号；每单可直接「送达」或跨骑手改派。
- 改派、送达、载量调整后，两侧路线、载量进度与顶部统计全部响应式即时重算。

### 配送闭环
- 新订单先按「时段 + 余量」自动分配（规则可选**余量优先**或**负载均衡**），所有骑手都满载则留在待分配区。
- 送达：订单立即从路线移出，完成时间（含骑手、时段快照）写入「送达存档」，支持撤销送达重新参与分配。

### 基础数据分开维护
- **订单地址**：地址、距离、时段、备注，独立增删与筛选。
- **骑手排班**：在班开关、电话，以及按时段逐个维护最大载单量（数字即时生效，超载时最远的订单自动退回并尝试改派他人）。
- **分配规则**：时段增删、分配策略、新订单是否自动分配。
- 四类数据（orders / riders / rules / archive）分别存放在浏览器 localStorage 独立键中，重新打开页面自动恢复，可在「分配规则」页一键清空恢复演示数据。

## 结构

```
src/
├── App.vue                     # 外壳：顶部统计 + 标签页
├── types.ts                    # 订单 / 骑手 / 规则 / 存档类型
├── store.ts                    # 调度核心：余量、自动分配、改派、送达、持久化
├── utils.ts                    # 时间格式化
└── components/
    ├── DispatchBoard.vue       # 调度台（待分配区 + 骑手路线）
    ├── OrderPanel.vue          # 订单地址维护
    ├── RosterPanel.vue         # 骑手排班与按时段载量
    ├── RulesPanel.vue          # 时段、分配规则、存档管理
    └── ArchivePanel.vue        # 送达存档与完成统计
```
